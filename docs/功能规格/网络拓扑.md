# WeMonitor — 网络拓扑

> 状态：已实现
> 最后更新：2026-07-30

## 1. 功能概述

通过网络拓扑页面（`/network`）可视化展示 N150 家庭网络环境，包括从 Internet 到 N150 上各服务的完整链路。

**统一画布**：使用 React Flow 单一画布，编辑器和查看器是同一个实例。默认**只读模式**（可缩放/平移/悬停查看），点击「编辑」解锁拖拽/连线/属性修改。

> 不再有独立的静态 SVG 渲染——编辑画布 = 查看画布，避免两套渲染对齐不一致。

## 2. 模式切换

| 模式 | 行为 |
|------|------|
| **只读**（默认） | 悬停节点查看 tooltip（名称+状态+端口）· 滚轮缩放 · 拖拽平移画布 · 禁用拖拽/连线/删除/双击编辑 |
| **编辑**（点击按钮） | 左侧面板拖入节点 · 节点 Handle 拖线连接 · 双击改属性 · Delete 删除 · 保存按钮出现 |

## 3. 拓扑结构

### 3.1 网络路径

**公网访问**（左列，不经过家庭网络）：
```
Internet → CF CDN → CF Tunnel → N150 → 服务
```

**局域网访问**（右列，走家庭网络）：
```
手机/电脑 → 路由器 → UFW → N150 → 服务
```

**N150 出站**（依赖家庭网络）：
```
N150 → 路由器 → 光猫 → ISP → Internet
```

### 3.2 节点类型

| 节点类型 | 说明 | 动态状态 |
|---------|------|---------|
| Internet | 互联网 | 无 |
| ISP（中国移动） | 运营商 | 无 |
| 光猫 | CMCC ONT（192.168.1.1） | Ping 检测 |
| 路由器 | 小米路由器（192.168.31.1） | Ping + API |
| 本地设备 | 手机/电脑 | 无 |
| Cloudflare CDN | CDN 节点 | 无 |
| Cloudflare Tunnel | Cloudflare 隧道 | cloudflared 进程状态 |
| UFW 防火墙 | N150 防火墙 | `ufw status` |
| N150 服务器 | 运行服务的主机 | 进程在线 + CPU/内存 |
| 服务节点 | WeMusic / WeMonitor / Webhook / WeDownload / SSH | TCP 健康检查 |

### 3.3 子节点（Child Nodes）

节点可以通过属性编辑弹窗添加**子节点**，子节点会贴附在主节点外侧（支持上/下/左/右四个方向），随主节点一起移动。

- 子节点使用虚线边框、稍小字号以区别于主节点
- 子节点可连接边（如：路由器 → UFW 子节点 → N150 主节点）
- 删除主节点时子节点级联删除
- 子节点支持复制（Ctrl+D），但复制时不会复制目标节点的子节点
- JSON 格式：`{ id, type, parentId, position:{x,y}, data:{ label, side, order, … } }`

## 4. 交互操作

### 4.1 只读模式

| 操作 | 方式 |
|------|------|
| 查看状态 | 悬停节点 → tooltip 显示名称、状态、端口 |
| 缩放 | 滚轮 |
| 平移 | 拖拽空白区域 |
| 进入编辑 | 点击工具栏「编辑」按钮 |

### 4.2 编辑模式

#### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Z` / `Cmd+Z` | 撤销（50 级历史栈） |
| `Ctrl+Y` / `Cmd+Shift+Z` | 重做 |
| `Ctrl+S` / `Cmd+S` | 快速保存 |
| `Ctrl+D` / `Cmd+D` | 复制选中节点（偏移 30px） |
| `Delete` | 删除选中的节点和边 |
| `Shift + 点击` | 多选 |
| `Shift + 拖拽空白` | 矩形框选 |

#### 撤销/重做

- 以下操作前会自动保存快照：拖拽节点、新增/删除节点、新增/删除边、修改属性（属性弹窗保存时）
- 进入/退出编辑模式的系统变更不会计入历史
- 撤销栈最多 50 步，超出自动移除最早记录
- 自动布局、复制节点、边重连等操作也会先存快照

#### 未保存修改提醒

编辑模式下，任何修改操作都会触发工具栏黄色警告文字 **「⚠ 有未保存的修改」**。保存、刷新或撤销到初始状态后消失。

刚进入编辑模式（不操作任何东西）不会触发提醒。

#### 节点操作

| 操作 | 方式 |
|------|------|
| 新增 | 左侧面板拖入画布（10 种模板） |
| 移动 | 拖拽（拖拽前自动存快照，支持撤销回退位置） |
| 编辑属性 | 双击 → 弹窗（标签/端口/宽度/颜色 + 子节点管理） |
| 添加子节点 | 双击 → 属性弹窗 → 「子节点」区域 → 选择位置（上/下/左/右）+ 输入名称 → 保存 |
| 删除子节点 | 双击父节点 → 属性弹窗 → 子节点列表中点「×」→ 保存 |
| 复制 | 选中 → `Ctrl+D`（不复制子节点） |
| 删除 | 选中 → 工具栏红色「删除选中」按钮或 `Delete` 键 |
| 自动布局 | 工具栏「自动布局」按钮 → 按 BFS 层级重新排列所有节点 |

#### 连线操作

| 操作 | 方式 |
|------|------|
| 新增 | 从节点下方蓝色圆点拖到目标节点 |
| 编辑属性 | 双击 → 弹窗（标签/线型/虚实/箭头） |
| 重连 | 拖住连线任意一端 → 拉到新节点上释放 |
| 删除 | 选中 → 工具栏「删除选中」按钮或 `Delete` 键 |

#### 框选（矩形选择）

- 按住 `Shift` 在空白处拖拽 → 矩形框选中范围内的节点和边
- 松开 `Shift` 后可拖拽平移画布（正常交互）
- 选中后可用 `Delete`、`Ctrl+D`、`Ctrl+Z` 等操作

#### 右键菜单

| 右键对象 | 菜单项 |
|---------|--------|
| 节点 | 复制 / 删除 / 编辑属性 |
| 边 | 删除 / 编辑属性 |

- 右键未选中的节点/边时自动选中
- 点击画布其他区域关闭菜单

#### 属性弹窗（PropertyModal）

**节点属性：**

| 字段 | 说明 |
|------|------|
| 标签 | 文本，`\n` 换行 |
| 端口号 | 数字，如 5174 |
| 节点宽度 | 数字，80~500 |
| 边框颜色 | 7 色板（自动/绿/橙/红/蓝/紫/灰） |
| 子节点 | 列表（位置标签 + 名称 + 删除按钮）+ 添加表单（位置下拉 + 名称输入） |

**边属性：**

| 字段 | 说明 |

| 线条走向 | 直线 / 阶梯 / 曲线 |
| 实线/虚线 | 切换按钮 |
| 方向箭头 | 切换开关（默认显示） |

## 5. 动态状态

### 状态来源

| 来源 | 方式 | 影响节点 |
|------|------|---------|
| 物理拓扑 | Ping | 光猫、路由器、N150 |
| 小米路由器 API | stok 认证 HTTP | 路由器详情 |
| 防火墙 | `ufw status verbose` | UFW |
| Tunnel | cloudflared 进程 | CF Tunnel、SSH |
| 健康检查 | TCP 探测 | N150、各服务 |

### 颜色规则

**优先级**：手动覆盖色 > 动态状态自动色。

| 颜色 | 含义 |
|------|------|
| 绿 | 在线/healthy/active |
| 橙 | 警告 |
| 红 | 异常/不可达 |
| 灰 | 未知/无动态状态 |

## 7. 版本历史

每次点击「保存」，系统会在写入 `topology.json` 之前自动创建版本快照。

### 存储

```
data/topology.json              ← 当前版本
data/topology-versions/
├── v_2026-07-22T10-30-00.json  ← 历史快照
├── v_2026-07-21T15-20-00.json
└── ...
```

- 每个版本是完整的 `topology.json` 副本
- 如果内容和上一个版本完全相同则跳过（去重）
- 最多保留 50 个版本，超出自动删除最旧的

### 操作

| 操作 | 方式 |
|------|------|
| 查看版本列表 | 工具栏「版本历史」→ 弹窗显示时间、节点数、连线数 |
| 预览版本内容 | 点击「预览」→ 展开节点/连线列表 |
| 恢复版本 | 点击「恢复」→ 二次确认 → 恢复前自动保存当前版本为快照 |

恢复后编辑器自动刷新加载恢复后的数据。

## 8. 配置持久化

```
编辑器 Save → POST /api/v1/topology-config → 写入 data/topology.json
页面加载 → GET /api/v1/topology-config → 读取 → React Flow 渲染
```

- **初始化**：首次 `GET` 时从 `lib/default-topology.json` 复制到 `data/topology.json`
- **data/ 目录**：`rsync --exclude data` 保护，不被部署覆盖

### JSON 格式

**节点**：
```json
{
  "id": "n150",
  "type": "topology",
  "parentId": null,
  "position": { "x": 330, "y": 330 },
  "data": {
    "label": "N150 服务器",
    "port": null,
    "dynamic": "n150",
    "healthIdx": -1,
    "width": 250,
    "color": null,
    "side": null,
    "order": null
  }
}
```

- `parentId`：子节点指向父节点的 ID，顶级节点为 `null`
- `side` / `order`：子节点在父节点旁的贴附位置和排序（`top` / `bottom` / `left` / `right`）
- `lineStyle`：替代 `style` 避免 React prop 冲突
- `arrow`：默认 `true`，兼容旧数据无此字段时视为显示箭头

**边**：
```json
{
  "id": "e-router-ufw",
  "source": "router",
  "target": "ufw",
  "label": "WiFi",
  "lineStyle": "solid",
  "edgeType": "smoothstep",
  "arrow": true
}
```

### 导出

工具栏「导出」按钮将当前拓扑数据下载为 `topology-YYYY-MM-DD.json` 文件，格式与 API 返回的 `GET /api/v1/topology-config` 一致，可直接用于备份或在其他环境恢复。

## 9. API

| 方法 | 端点 | 说明 |
|------|------|------|
| `GET` | `/api/v1/topology-config` | 读取拓扑 JSON |
| `POST` | `/api/v1/topology-config` | 保存拓扑 JSON（自动创建版本快照） |
| `GET` | `/api/v1/topology-config/versions` | 版本列表 |
| `GET` | `/api/v1/topology-config/versions/:id` | 获取指定版本完整数据 |
| `POST` | `/api/v1/topology-config/versions/:id/restore` | 恢复指定版本（恢复前自动保存当前版本） |
| `GET` | `/api/v1/physical-topology` | 物理状态 |
| `GET` | `/api/v1/firewall/status` | 防火墙状态 |
| `GET` | `/api/v1/tunnel/status` | 隧道状态 |
| `GET` | `/api/v1/health` | 健康检查 |

## 11. 已知限制

- 编辑模式无权限约束（服务供可信用户使用）
- 撤销栈存储完整节点/边快照，大量节点时可能占用较多内存
- 自动布局仅排布顶级节点，子节点位置不参与计算
- 只读模式下鼠标悬停 tooltip 只显示有动态状态的节点
- 导出仅支持 JSON 格式，不支持图片导出
